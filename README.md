# 🪔 Diwali Sales Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Diwali sales data using Python.

The objective is to understand customer purchasing behavior and identify key customer segments and product categories that contribute to sales.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Analysis Performed

The analysis covers:

- Gender-wise purchasing behavior
- Age group analysis
- Marital status
- State-wise sales
- Occupation-wise purchasing
- Product category analysis

## 📊 Key Insights

- Married women in the 26–35 age group are an important customer segment.
- UP, Maharashtra and Karnataka show strong purchasing activity.
- IT, Healthcare and Aviation professionals are notable buyer segments.
- Food, Clothing and Electronics are important product categories.

## 🎯 Conclusion

The analysis helps identify high-value customer segments and understand purchasing patterns, which can support better marketing and sales strategies.
